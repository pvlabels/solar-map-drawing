## Read the sales order and establish zones first

Run `chat_job.py prepare` on the selected PDF. It saves `order-layout-candidates.json` with item-bound sizes, SKUs, evidence, hole requests and production-profile candidates. Confirm the exact map item, ordered width/height and material from its sales-order row **before choosing a map canvas or callout positions**. The PDF page size, source-map aspect ratio, a different item on the same order, and the source drawing's nominal scale are not placard dimensions. Preserve custom sizes and item codes. Resolve unreadable/contradictory dimensions rather than guessing.

Create `placard.order` from the confirmed row and source hash. Choose a matching measured production-size profile or supply a source-confirmed actual cut size. Plan the cutline, warning/title, optional lower warnings/legend and footer, then use only the remaining work zone for geometry and, in labeled/finished modes, callouts. Header length, operational notes and title position change that work zone. Do not apply one percentage layout or a universal 0.05-inch reduction; see the zone reference's measured exceptions. Requested holes need confirmed positions/diameters.
